🔎 WvW Relink Checker

Paste each alliance guild's name (one per line) and this tool looks up which WvW matchmaking team/server it landed on, using the official ArenaNet API. Everything runs locally in your browser — nothing is sent anywhere except the official GW2 API.

Note: the name must match the in-game guild name exactly (the API search is an exact match, not a tag or partial search). Max 60 entries per run.

Guild Tag Region Server (link)
